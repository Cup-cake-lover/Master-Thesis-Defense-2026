# Master thesis defense 

This repository contains assets from my master thesis defense. I have utilized the [revealjs](https://revealjs.com/) plugin available within the [Quarto](https://quarto.org/) ecosystem for additional element control in the slides. There are some additional js plugins which I added for data visualisation. (Some of these plugins are vibecoded as I didn't have background in js :/). Unfortunately I am currently only the skeleton of the presentation as the images are too large for the repo. 

To compile the the .qmd file simply use

```bash
quarto preview ./presentation.qmd --no-browser 
```
Feel free to fork the repo!
